# DXスコアレート β版（テスト用）

これは「DXスコアレート」のβ版です。正式版に入れる予定の新しい機能や見た目を、先に試してもらうためのものです。

動作が不安定だったり、正式版とは表示や結果が異なったりすることがあります。気づいたことがあれば、ぜひ教えてください。

## β版で試してほしいこと

正式版との主な違いは次のとおりです。

- **結果画面のデザインを一新**：レートを大きな札で表示し、札を押すとその上位50譜面の一覧に切り替わります。
- **ジャケット画像の表示**：一覧の各曲にジャケット画像を表示します。
- **表示の安定性の改善**：公式サイトのデザインの影響で画面が崩れないようにしました。

レートの計算方法そのものは正式版と同じです。

## ブックマークの登録

以下のコードを、ブックマークのURL欄に登録します。正式版のブックマークとは別に登録してください（名前を「DXスコアレート β」などにすると区別しやすいです）。

```
javascript:(()=>{const s=document.createElement('script');s.src='https://n4f1316.github.io/dxscore-tools/beta/dxscore_rating.js?'+Date.now();document.body.appendChild(s);})();void(0);
```

### PC / Chrome

1. `Ctrl + Shift + B`（Macは `Command + Shift + B`）でブックマークバーを表示します。
2. ブックマークバーの空いている部分を右クリックし、「ページを追加」を選びます。
3. 「名前」に「DXスコアレート β」と入力します。
4. 「URL」に上のコードを1行まるごと貼り付けて保存します。

コードをアドレスバーに直接貼り付けても動きません。必ずブックマークとして登録してください。

### iPhone / Safari

1. 適当なページを開き、共有ボタンから「ブックマークを追加」で保存します。
2. ブックマーク一覧から、今保存したブックマークを「編集」します。
3. 名前を「DXスコアレート β」に変更し、URL欄を上のコードに置き換えて保存します。

### Android / Chrome

1. 適当なページをブックマークに追加します。
2. ブックマークを編集し、名前を「DXスコアレート β」に変更して、URL欄を上のコードに置き換えます。
3. 実行するときは、アドレスバーに「DXスコアレート β」と入力し、候補に出てきたブックマークをタップします（ブックマーク一覧からタップしても実行されません）。

## 使い方

1. [maimai DX NET](https://maimaidx.jp/maimai-mobile/) にログインします（どのページを開いていても構いません）。
2. 登録したブックマークを実行します。
3. レコードのページを順番に読み込むため、数秒〜十数秒ほど待ちます。
4. 結果画面が表示されます。左上に「DXスコアレート β版」と出ていれば、β版が動いています。
5. 「☆7まで」「☆5まで」の札を押すと、それぞれの上位50譜面に切り替わります。「閉じる」で元の画面に戻ります。

## 確認してほしいポイント

テストの際は、特に次の点を見てもらえると助かります。

- 最後まで実行できたか（エラーが出た場合は、そのメッセージ）
- 使った端末とブラウザ（例：iPhone / Safari、Windows / Chrome）
- ジャケット画像が表示されたか、表示されない曲はあったか
- 画面の崩れや、文字の重なり・はみ出しがないか（スマホの縦画面・横画面も）
- レートの数値が正式版と同じになっているか
- 見やすさや使いやすさについての感想

画面の崩れなどは、スクリーンショットを添えてもらえると原因を特定しやすくなります。
