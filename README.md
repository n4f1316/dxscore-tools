# 2fRATE

maimaiでらっくす の公式サイト「maimaiでらっくすNET」上で動く、でらっくスコアを使った独自レート「2fRATE」の計算ツールです（非公式・ファンメイド）。

ブックマークレットとして登録し、maimaiでらっくすNET にログインした状態で実行すると、自分のでらっくスコアから 2fRATE を計算して表示します。

## できること

- でらっくスコアの☆と譜面定数から、上位50譜面の平均で 2fRATE を計算
- 「☆7まで」「☆6まで」「☆5まで」の3種類のレートを同時に表示
- 上位50譜面の一覧（ジャケット、DX/ST、難易度、譜面定数、☆、最大値との差、単曲レート値）を表示
- プレイヤー名・アイコン・称号の表示
- レート対象曲50譜面を1枚の画像（5列×10行）にまとめて保存

## レートの計算方法

### ☆の決まり方

☆は、でらっくスコアの取得率（現在値 ÷ 最大値）で決まります。

| ☆ | 取得率 |
|---|---|
| ☆7 | 100%（理論値） |
| ☆6 | 99%以上 |
| ☆5 | 97%以上 |
| ☆4 | 95%以上 |
| ☆3 | 93%以上 |
| ☆2 | 90%以上 |
| ☆1 | 85%以上 |

計算には、☆を小数第一位まで使います。小数部分は「次の☆までの進み具合」を10段階で表したもの（切り捨て）です。たとえば☆6の範囲（99%〜100%）のちょうど中間なら☆6.5、理論値まであと少しでも☆6.9です。☆1未満（85%未満）の譜面は0として扱います。

### 単曲レート値

```
単曲レート値 =（譜面定数 × 譜面定数 × ☆の整数部分
             ＋ 譜面定数 × 譜面定数 × ☆の小数部分 × 0.5）÷ 100
             ＋ 0.1（☆がレートの上限に達した場合のみ）
             ＋ 希少ボーナス（下記。☆7まで・☆6まで のみ）
```

☆の小数部分は半分の重みで加算されます。☆がそのレートの上限（☆7まで は☆7、☆6まで は☆6、☆5まで は☆5）に達した譜面には、さらに 0.1 が加わります。下の表は「☆7まで」の例です。

| 譜面定数 | ☆6.0 | ☆6.4 | ☆6.9 | ☆7.0 |
|---|---|---|---|---|
| 13.8 | 11.426 | 11.807 | 12.283 | 13.431 |
| 15.0 | 13.500 | 13.950 | 14.512 | 15.850 |

### 希少ボーナス

でらっくスコアの全国ランキング（上位100人）で☆6以上（☆6＋☆7）を達成している人が少ない譜面は、自分が☆6以上を達成していると、「☆7まで」「☆6まで」の単曲レート値に次の値が加わります（「☆5まで」には加わりません）。

| 上位100人のうち☆6以上の人数 | 加算 |
|---|---|
| 3人以下 | +0.15 |
| 10人以下 | +0.10 |
| 20人以下 | +0.05 |

人数は `ranking/` の集計データ（`star6Count` ＋ `maxCount`）から求めます。集計データがない譜面には加算されません。

### 2fRATE

単曲レート値の高い上位50譜面の平均が 2fRATE です（50譜面に満たない場合も50で割ります）。

- **☆7まで**：上の計算式そのままのレートです。☆7（理論値）の譜面に +0.1 されます。希少ボーナスも加わります。
- **☆6まで**：☆7の譜面を☆6.0として計算します。☆6.0以上の譜面に +0.1 されます。希少ボーナスも加わります。
- **☆5まで**：☆5を超える譜面を☆5.0として計算します。☆5.0以上の譜面に +0.1 されます（希少ボーナスはありません）。

上位50譜面は、レートの種類ごとに別々に選んでいます。

## ブックマークの登録

以下のコードを、ブックマークのURL欄に登録します。

### レート計算用

```
javascript:(()=>{const s=document.createElement('script');s.src='https://n4f1316.github.io/dxscore-tools/dxscore_rating.js?'+Date.now();document.body.appendChild(s);})();void(0);
```

### 登録方法（PC / Chrome）

1. `Ctrl + Shift + B`（Macは `Command + Shift + B`）でブックマークバーを表示します。
2. ブックマークバーの空いている部分を右クリックし、「ページを追加」を選びます。
3. 「名前」に「2fRATE」など好きな名前を入力します。
4. 「URL」に上のコードを1行まるごと貼り付けて保存します。

コードをアドレスバーに直接貼り付けても動きません。必ずブックマークとして登録してください。

### 登録方法（iPhone / Safari）

1. 適当なページを開き、共有ボタンから「ブックマークを追加」で保存します。
2. ブックマーク一覧から、今保存したブックマークを「編集」します。
3. 名前を変更し、URL欄を上のコードに置き換えて保存します。

### 登録方法（Android / Chrome）

1. 適当なページをブックマークに追加します。
2. ブックマークを編集し、名前を「2fRATE」などに変更して、URL欄を上のコードに置き換えます。
3. 実行するときは、アドレスバーにブックマークの名前を入力し、候補に出てきたブックマークをタップします（ブックマーク一覧からタップしても実行されません）。

## 使い方

1. [maimaiでらっくすNET](https://maimaidx.jp/maimai-mobile/) にログインします（どのページを開いていても構いません）。
2. 登録したブックマークを実行します。
3. レコードのページを順番に読み込むため、数秒〜十数秒ほど待ちます。
4. プレイヤー情報、3種類の 2fRATE、上位50譜面の一覧が表示されます。
5. レートの札（「☆7まで」など）を押すと、そのレートの上位50譜面に切り替わります。「閉じる」で元の画面に戻ります。

### 表の見方

| 項目 | 内容 |
|---|---|
| ジャケット | 楽曲のジャケット画像。同名の別曲は、判別できた場合に曲名の横にジャンルを表示 |
| DX / ST | でらっくす譜面 / スタンダード譜面 |
| 難易度 | BASIC（緑）、ADVANCED（黄）、EXPERT（赤）、MASTER（紫）、Re:MASTER（白地に紫） |
| 譜面定数 | `*` 付きは定数表にない譜面で、レベル表示からの概算値（下限） |
| ☆ | ☆1・2は黄緑、☆3・4はオレンジ、☆5・6は黄色、☆7は虹色で表示 |
| MAX差 | でらっくスコア最大値との差（理論値は `MAX`） |
| レート値 | その譜面の単曲レート値 |

### 画像として保存する

結果画面のレートの札の下にある「上位50を画像にする」ボタンを押すと、別のタブに画像が表示されます。スマホは画像を長押しして「写真に保存」、PCは画像の上の「画像をダウンロード」から保存できます。画像には、プレイヤー情報と選んだレート、上位50譜面（順位・ジャケット・曲名・DX/ST・難易度・譜面定数・☆・単曲レート値）が載ります。

### ランキングビューア（viewer.html）

楽曲別のでらっくスコア全国ランキング（上位100人）から、譜面ごとに1位・50位・100位のスコア、平均取得率、☆7・☆6の人数を集計します。プレーヤー名は保存しません。
集計結果は、閲覧専用のビューアで誰でも見られます（ログイン不要）。

https://n4f1316.github.io/dxscore-tools/viewer.html

## 注意事項

- 非公式のファンメイドツールです。株式会社セガおよび関連会社とは一切関係ありません。
- 楽曲のジャケット画像の著作権は、各権利者に帰属します。
- 計算と画像の作成はすべてブラウザ内で行っています（譜面定数表などのデータを、このリポジトリから読み込むだけです）。プレイデータが外部（2fRATE のランキング用サーバー）に送信されるのは、結果画面から「ランキングに登録」したときだけです。
- 公式サイトへの負荷を抑えるため、ページの読み込みは間隔を空けて行っています。短時間に何度も連続で実行しないようにしてください。
- 公式サイトの構成が変わると、動作しなくなることがあります。
- 公式サイトの機能の利用状況（コースの加入状況など）によっては、一部のページが見られず正しく計算できない場合があります。
