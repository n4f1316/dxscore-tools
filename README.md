# dxscore-tools

maimaiでらっくす の公式サイト「maimaiでらっくすNET」上で動く、でらっくスコアを使った独自レートの計算ツールです（非公式・ファンメイド）。

ブックマークレットとして登録し、maimaiでらっくすNET にログインした状態で実行すると、自分のでらっくスコアから「DXスコアレート」を計算して表示します。

## できること

- でらっくスコアの☆と譜面定数から、上位50譜面の平均で「DXスコアレート」を計算
- 「☆7まで」と「☆5まで（☆6以上を☆5として計算）」の2種類のレートを表示
- 上位50譜面の一覧（定数、☆、最大値との差、レート値）を表示

## レートの計算方法

譜面ごとのレート値は次の式で計算します。

```
単曲レート値 = 譜面定数 × 譜面定数 × ☆の数 ÷ 1000
```

☆の数は、でらっくスコアの取得率（現在値 ÷ 最大値）で決まります。

| ☆ | 取得率 |
|---|---|
| ☆7 | 100%（理論値） |
| ☆6 | 99%以上 |
| ☆5 | 97%以上 |
| ☆4 | 95%以上 |
| ☆3 | 93%以上 |
| ☆2 | 90%以上 |
| ☆1 | 85%以上 |

DXスコアレートは、レート値の高い上位50譜面の平均です（50譜面に満たない場合も50で割ります）。

## ブックマークの登録

以下のコードを、ブックマークのURL欄に登録します。

### レート計算用

```
javascript:(()=>{const s=document.createElement('script');s.src='https://n4f1316.github.io/dxscore-tools/dxscore_rating.js?'+Date.now();document.body.appendChild(s);})();void(0);
```

### 登録方法（PC / Chrome）

1. `Ctrl + Shift + B`（Macは `Command + Shift + B`）でブックマークバーを表示します。
2. ブックマークバーの空いている部分を右クリックし、「ページを追加」を選びます。
3. 「名前」に「DXスコアレート」など好きな名前を入力します。
4. 「URL」に上のコードを1行まるごと貼り付けて保存します。

### 登録方法（iPhone / Safari）

1. 適当なページを開き、共有ボタンから「ブックマークを追加」で保存します。
2. ブックマーク一覧から、今保存したブックマークを「編集」します。
3. 名前を変更し、URL欄を上のコードに置き換えて保存します。

### 登録方法（Android / Chrome）

1. 適当なページをブックマークに追加します。
2. ブックマークを編集し、名前を「DXスコアレート」などに変更して、URL欄を上のコードに置き換えます。
3. 実行するときは、アドレスバーにブックマークの名前を入力し、候補に出てきたブックマークをタップします（ブックマーク一覧からタップしても実行されません）。

## 使い方

1. [maimaiでらっくすNET](https://maimaidx.jp/maimai-mobile/) にログインします（どのページを開いていても構いません）。
2. 登録したブックマークを実行します。
3. レコードのページを順番に読み込むため、数秒〜十数秒ほど待ちます。
4. 画面にプレイヤー名、2種類のDXスコアレート、上位50譜面の一覧が表示されます。
5. 表の上のボタンで「☆7までの上位50」と「☆5までの上位50」を切り替えられます。「閉じる」で元の画面に戻ります。

### 表の見方

| 項目 | 内容 |
|---|---|
| 譜面 | DX / ST（スタンダード）、難易度、レベル |
| 定数 | 譜面定数。`*` 付きは定数表にない譜面で、レベル表示からの概算値（下限） |
| ☆ | でらっくスコアの☆。小数部分は次の☆までの進み具合（計算には整数部分のみ使用） |
| MAX差 | でらっくスコア最大値との差（理論値は `MAX`） |
| レート値 | その譜面のレート値 |

## 注意事項

- 非公式のファンメイドツールです。株式会社セガとは一切関係ありません。
- 公式サイトの構成が変わると、動作しなくなることがあります。
- 取得したデータを外部に送信することはありません。すべてブラウザ内で計算しています。
- 公式サイトへの負荷を抑えるため、ページの読み込みは間隔を空けて行っています。短時間に何度も連続で実行しないようにしてください。
- 公式サイトの機能の利用状況（コースの加入状況など）によっては、一部のページが見られず正しく計算できない場合があります。
