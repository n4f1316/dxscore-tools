2fRATE レート計算ブックマーク

maimai DX NET にログインした状態でブックマークから実行すると、あなたのでらっくスコアから 2fRATE を計算します。

できること

  • 「☆7まで」「☆6まで」「☆5まで」の3種類の 2fRATE と、ランクを表示
  • レート対象曲（上位50譜面）を、ジャケット・譜面定数・☆・単曲レート値つきで一覧表示
  • レート対象曲50譜面を1枚の画像にして保存（名前・称号を隠すこともできます）
  • 次に☆を伸ばすとよい譜面を「おすすめ楽曲」として表示
  • ランキングへの登録・更新

1コードをコピーする

下のコードがブックマークの中身になります。1行まるごとコピーしてください。

PCなら ★ 2fRATE をブックマークバーへドラッグしても登録できます

2ブックマークに登録する

  1. Ctrl + Shift + B（Macは ⌘ + Shift + B）でブックマークバーを表示します。
  2. ブックマークバーの空いているところを右クリックし、ページを追加（Edgeは お気に入りを追加）を選びます。
  3. 「名前」に 2fRATE など、わかりやすい名前を入力します。
  4. 「URL」に、コピーしたコードを貼り付けて保存します。

上の「★ 2fRATE」ボタンをブックマークバーへドラッグ＆ドロップするだけでも登録できます。

  1. Safariでこのページを開いたまま、共有ボタン（□に↑）をタップし、ブックマークを追加で保存します。
  2. ブックマーク一覧（本のアイコン）を開き、右下の 編集 をタップして、今保存したブックマークを選びます。
  3. 名前を 2fRATE に変更します。
  4. URL欄の中身をすべて消し、コピーしたコードを貼り付けて 完了 をタップします。

URL欄はとても長くなります。古いURLが残らないよう、全部消してから貼り付けてください。

  1. Chromeでこのページを開いたまま、右上の ⋮ から ☆（ブックマークに追加）をタップします。
  2. 画面下に出る 編集（または ⋮ → ブックマーク から、今追加したものの ⋮ → 編集）を開きます。
  3. 名前を 2fRATE に変更します。
  4. URL欄の中身をすべて消し、コピーしたコードを貼り付けて戻ります（自動で保存されます）。

3maimai DX NET で実行する

  1. maimai DX NET にログインします（どのページを開いていても構いません）。
  2. ブックマークバーの 2fRATE をクリックします。
  3. 数秒〜十数秒待つと、結果画面が表示されます。
  1. Safariで maimai DX NET にログインします（どのページを開いていても構いません）。
  2. ブックマーク一覧（本のアイコン）を開き、2fRATE をタップします。
  3. 数秒〜十数秒待つと、結果画面が表示されます。
  1. Chromeで maimai DX NET にログインします（どのページを開いていても構いません）。
  2. アドレスバーをタップし、2fRATE（登録した名前）と入力します。
  3. 候補に出てくる、☆マークのついた 2fRATE をタップします。
  4. 数秒〜十数秒待つと、結果画面が表示されます。
Android の Chrome では、ブックマーク一覧からタップしても実行されません。必ずアドレスバーに名前を入力して、候補から選んでください。
コードをアドレスバーに直接貼り付けても動きません（貼り付けると先頭の javascript: が消えてしまうため）。必ずブックマークとして登録してから実行してください。

結果画面の見方

レートの札「☆7まで」「☆6まで」「☆5まで」の3種類の 2fRATE。札を押すと、そのレートのレート対象曲に切り替わります。計算方法はレートとランクのしくみへ。
DX / STでらっくす譜面 / スタンダード譜面
譜面定数* 付きは定数表にない譜面で、レベル表示から見積もった値です。
☆でらっくスコアの☆。小数部分は次の☆までの進み具合です。
MAX差でらっくスコア最大値（理論値）までの差。理論値なら MAX。
レート値その譜面の単曲レート値。

ランキングへの登録

結果画面の ランキングに登録・更新する から、ランキングに自分の記録を載せられます。登録は任意です。

ユーザー名とPINは、2fRATE のランキング専用のものを自分で決めます（maimai DX NET や SEGA ID のパスワードは絶対に入力しないでください）。次回以降、同じユーザー名とPINで記録を更新できます。PINを忘れると更新できなくなるので、控えておいてください。

公開されるのは、表示名（または「匿名#記号」）、プレイヤーアイコン、3種類のレートとランク、ベスト枠（公開を選んだ場合のみ）です。ユーザー名とPINは公開されません。

うまくいかないとき

ブックマークを押しても何も起きない

URL欄の先頭が javascript: で始まっているか確認してください。貼り付けたときに消えてしまうことがあります。

Android の Chrome は、ブックマーク一覧からではなくアドレスバーに名前を入力して実行してください。

「ログインしていないようです」と表示される

maimai DX NET にログインしていないか、ログインの有効期限が切れています。一度ログインし直してから、もう一度実行してください。

maimai DX NET 以外のページで実行した場合は「maimai DX NET にログインした状態で実行してください」と表示されます。

途中で止まる・エラーが出る

通信状況が悪いと、レコードの読み込みに失敗することがあります。少し時間をおいてから、もう一度実行してください。

公式サイトの機能の利用状況（コースの加入状況など）によっては、一部のページが見られず正しく計算できない場合があります。

レートや譜面定数が古い気がする

ブックマークは実行のたびに最新のプログラムを読み込みます。譜面定数は新バージョンの稼働後、順次更新します。

β版（テスト版）

新機能を先に試したい方へ

正式版に入れる前の新機能を試せるβ版です。動作が不安定なことがあります。正式版とは別のブックマーク（名前を「2fRATE β」など）として登録してください。登録・実行の手順は正式版と同じです。
